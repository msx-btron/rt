00 / Command

The gate

Top-level Makefile · BSD make · fail on a finding

From the repository root, make security runs sec-scalar, then sec-verify, then scripts/security_report.py. Each scanner target checks that clang, flawfinder, and cppcheck are on PATH. A missing tool exits 1.

The recipes are plain shell, duplicated per target, so the BSD make that ships with macOS runs them. There is no GNU define. make security-report prints the tree without scanning again.

clang --analyze can print a warning and still exit 0. flawfinder exits 0 when it has hits. The Makefile does not trust those statuses. It greps the clang log for warning: or error:, greps the flawfinder log for a :line: hit, and passes --error-exitcode=1 to cppcheck.

01 / Tools

Three scanners

Same flags as the host oracle, without -O2 and without -Werror

Clang

Analyzer

clang --analyze -std=c99 -Wall -Wextra -Wformat=2 -fno-strict-aliasing -fno-builtin -Iinclude -Xanalyzer -analyzer-output=text. Optimization is off so the analyzer sees the source, not a folded binary.

Flawfinder · level 4

Pattern hits

flawfinder --minlevel=4 --quiet on the scalar sources and on the two oracle files. Level 5 is marked critical in the tree. Level 2 notes on fixed char arrays stay below the gate.

Cppcheck

Warning and portability

cppcheck -j4 --std=c99 --enable=warning,portability --error-exitcode=1 --quiet -Iinclude. Style checks are not part of this gate.

02 / Scope

What is scanned

Four scalar C files · two oracle files · headers they include

Valgrind does not run in this gate. Coverity Scan and CodeChecker are not invoked. clang --analyze is the semantic scanner that does run.

03 / CI

SQCSA Test Suite

.github/workflows/ci.yml · job id sqcsa · one scan job

GitHub Actions runs the same command on Ubuntu 24.04. The job installs clang, cppcheck, flawfinder, and python3, then runs make security. A finding fails the job.

The workflow summary depends on this job. There is not a second security job beside it. The QEMU and native jobs build and test. They do not repeat the scan.
